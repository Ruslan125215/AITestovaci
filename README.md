# 🎮 Pixel Arcade

**Pixel Arcade** je školní projekt zaměřený na historii retro videoher, arkádových automatů a pixel artu.

## 📖 O projektu

Web představuje nejvýznamnější hry a zařízení, které ovlivnily vývoj videoherního průmyslu. Součástí projektu je časová osa historických milníků, galerie inspirovaná pixel artem a stránka se zdroji.

## 📑 Obsah webu

- 🏠 **Domů** – představení tématu retro videoher
- ⏳ **Historie** – významné hry a zařízení od roku 1972 do roku 1989
- 🖼️ **Galerie** – ukázky pixel artu
- 🤖 **Zdroje a AI** – použité zdroje a informace o využití AI

## 🛠️ Použité technologie

- HTML5
- CSS3
- GitHub Pages

## 🤖 Využití umělé inteligence

Při tvorbě projektu byly použity nástroje umělé inteligence:

- **Claude (Anthropic)** – pomoc s tvorbou textového obsahu webu.
- **Gemini (Google)** – pomoc s vytvořením dokumentace projektu (README).

Veškerý vygenerovaný obsah byl zkontrolován a upraven autorem projektu.
